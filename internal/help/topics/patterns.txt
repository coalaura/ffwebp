USAGE:
   ffwebp [global options]

TOPIC:
   Path patterns for input (-i) and output (-o)

INPUT PATTERNS:
   - Repeat -i for ordered files or patterns; patterns expand in place.
   - Globs: *, ?, [..] (quote them so ffwebp expands them on every platform)
   - Glob results sort numeric filename parts naturally: 1, 2, 10.
   - Numeric sequences: %d, %02d (all matching inputs, sorted numerically)
   - Explicit files retain their order and may be repeated. Stdin (-) is allowed once.

OUTPUT PATTERNS:
   - %d, %02d sequences (first output is --start-number, default 1)
   - Templates (GNU-parallel style):
       {}    full input path
       {.}   input path without last extension
       {/}   basename (file name)
       {/.}  basename without extension
       {//}  directory (no trailing slash)
       {#}   sequence number (uses --start-number)
   - Tile templates with --split (zero-based, left to right, top to bottom):
       {r}   tile row
       {c}   tile column
       {i}   tile index

EXAMPLES:
   ffwebp -i "*.png" -o "{/.}.webp"
   ffwebp -i "frames/%03d.png" -o "out/frame-{#}.png" --start-number 10
   # First output: out/frame-10.png, then out/frame-11.png
   ffwebp -i "frames/%d.png" -o "out/{/.}-%03d-{#}-{r}-{c}-{i}.png" --start-number 10 --split 2x2
   # If the first input is 2.png: 2-010-10-0-0-0.png, 2-010-10-0-1-1.png,
   #                2-010-10-1-0-2.png, 2-010-10-1-1-3.png (under out/)
   ffwebp -i "images/*.jpg" -o "out/{/.}.avif"
   ffwebp -i first.png -i second.png -i third.png --join 2x2 joined.png
   # Bottom-right cell stays empty; default background is transparent.
   ffwebp -i "tiles/*.png" --join 3xauto joined.png
   ffwebp -i cover.png -i "frames/%03d.png" --join autox1 strip.png

NOTES:
   - Output codec is inferred from the final extension unless --codec is set.
   - With multiple inputs, output must be a pattern or directory, unless using --join.
   - --join writes one file or stdout; output directories and patterns are rejected.
   - --join and --split are mutually exclusive. Positional arguments specify output only.
   - Ordinary templates, sequence numbers and tile templates can be combined.
   - Without a tile template, --split adds _r0_c0, _r0_c1, etc. before the extension.
